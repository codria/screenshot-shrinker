# Screenshot Shrinker

スクリーンショットのトリミング・モザイク・リサイズ・JPEG圧縮をまとめて行う Android アプリ。

## 機能

- **トリミング** — 4角・4辺ハンドルで自由にクロップ。アスペクト比ロック、端スナップ、Undo/Redo 対応
- **モザイク** — 複数領域を独立指定。粗さ調整・Undo/Redo 対応
- **プリセット** — トリミング＋モザイク設定を3スロットに保存。別の画像セットへワンタップで再適用
- **連結** — 複数画像を縦または横に結合
- **リサイズ** — 出力幅をプリセット（100% / 50% / 40% / 30% / 20% / 1080px / 768px）またはカスタム %で指定
- **JPEG 品質調整** — スライダーで 1〜100 を指定。推定ファイルサイズをリアルタイム表示
- **共有受け取り** — 他アプリからの `ACTION_SEND` / `ACTION_SEND_MULTIPLE` で直接起動

## 画面構成

| 画面 | 役割 | 主な操作・設定 | 遷移先 |
|---|---|---|---|
| 編集画像リスト | 画像選択とプリセット管理の起点 | 画像追加・削除、各画像のトリミング / モザイク設定、プリセット保存・適用 | トリミング / モザイク / 出力設定 |
| トリミング | クロップ範囲の指定 | ハンドルドラッグ、アスペクト比ロック、端スナップ、Undo/Redo、プリセット | 編集画像リスト |
| モザイク | モザイク領域の配置 | 領域追加・削除・移動・リサイズ、粗さ調整、Undo/Redo、プリセット | 編集画像リスト |
| 出力設定 | 出力パラメーターの設定と確認 | 連結方向（縦 / 横）、リサイズ、JPEG 品質（推定ファイルサイズ表示） | 保存完了 |
| 保存完了 | 保存結果の確認 | ギャラリーで開く・共有・破棄・最初からやり直し | — |

## 動作環境

| 項目 | 値 |
|---|---|
| 最小 SDK | 26 (Android 8.0) |
| ターゲット SDK | 36 |
| 言語 | Kotlin |

## ビルド

Android Studio で開き、そのまま Run。外部依存は Gradle が自動取得。

```
./gradlew assembleDebug
```

## 保存先

`Pictures/ScreenshotShrinker/` (MediaStore 経由)

## 権限

特別な権限は不要です。画像の選択はシステムのフォトピッカー、保存は MediaStore API を使用しているため、`uses-permission` の宣言はありません。
